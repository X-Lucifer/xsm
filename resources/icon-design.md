# XSM icon

Created with the built-in image generation tool; exported to the multi-size Windows ICO container by `scripts/build-icon.ps1`.

Design prompt: “Flat modern Windows services manager icon. Graphite rounded tile, ivory four-pane window and bold warm-orange service gear. Clear silhouette at 16–24 pixels; restrained 2D geometry, no wordmark, no blue/cyan, no metallic material or glossy bevel, transparent outside the tile.”

The PNG is the current working design source. EXE and window resources both use `xsm.ico`, resource ID 101.
